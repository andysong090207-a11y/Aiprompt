# 계좌찰칵 📸💸

행사장이나 포장마차에 붙은 계좌번호를 **카메라로 찍으면** 은행·계좌번호를 읽어서
**토스 송금 화면으로 바로 연결**하거나 **클립보드에 복사**해 주는 웹앱(PWA)입니다.

- 앱스토어 설치 없이 아이폰/안드로이드 브라우저에서 동작
- "홈 화면에 추가"하면 일반 앱처럼 실행
- 글자 인식(OCR)은 **폰 안에서** 처리하므로 사진이 서버로 전송되지 않음

## 사용 방법

1. 앱을 열고 은행명과 계좌번호를 화면의 **네모 안에** 맞춘 뒤 파란 버튼을 누릅니다.
2. 인식된 은행과 계좌번호를 확인합니다. 틀린 곳이 있으면 직접 고칠 수 있습니다.
   - 번호가 여러 개 보이면 위쪽 후보 버튼에서 고르면 됩니다.
3. 원하는 버튼을 누릅니다.
   - **토스로 송금하기**: 토스 앱 송금 화면이 은행·계좌(·금액)가 채워진 채로 열립니다.
   - **계좌번호 복사 / 은행+계좌 복사**: 클립보드에 복사합니다. 카카오뱅크나 다른 은행 앱에 붙여 넣으면 됩니다.
4. 최근에 보낸 계좌 5개는 첫 화면 아래에 남습니다(이 폰에만 저장됨).

> ⚠️ OCR은 틀릴 수 있습니다. 송금 전에 토스에 나오는 **받는 사람 이름**이 맞는지 꼭 확인하세요.

## 동작 방식

| 단계 | 구현 |
|---|---|
| 촬영 | `getUserMedia` 후면 카메라 미리보기 → 가이드 네모 영역만 잘라냄. 카메라를 못 쓰면 기본 카메라/사진 선택으로 대체 |
| 전처리 | 확대·흑백·대비 늘리기 (`js/app.js` `preprocess`) |
| OCR | [Tesseract.js](https://github.com/naptha/tesseract.js) v5, 한국어+영어, 브라우저 안에서 실행 |
| 계좌 추출 | `js/parser.js`: O→0, l→1 같은 오인식 보정 → 10~16자리 숫자 묶음 찾기 → 전화번호·날짜 제외 → 가까운 은행 키워드 연결 → 키워드가 없으면 번호 형식으로 은행 추정(카카오 3333…, 토스 1000-…, 우리 1002-… 등) |
| 토스 연결 | `supertoss://send?bank=국민&accountNo=12345678901234&amount=10000` 딥링크. 앱이 안 열릴 때를 대비해 계좌를 클립보드에도 복사 |

> 토스 딥링크(`supertoss://send`)는 토스가 공개한 공식 API가 아니라 커뮤니티에서 쓰는 방식이라, 토스 앱 업데이트로 바뀔 수 있습니다.
> 바뀌면 `js/parser.js`의 `buildTossLink`와 `js/banks.js`의 `toss` 값만 고치면 됩니다.

## 파일 구조

```
index.html            화면 3개 (촬영 / 인식 중 / 결과)
css/style.css
js/app.js             카메라, OCR, 화면 동작
js/parser.js          계좌번호·은행 추출 (순수 함수, 테스트 대상)
js/banks.js           은행 목록, 별칭, 토스용 은행명
sw.js                 오프라인 캐시 (서비스 워커)
manifest.webmanifest  홈 화면 추가용
tests/                Node 내장 테스트
```

## 개발

```bash
npm test     # 계좌 추출 로직 테스트
npm start    # http://localhost:8080 에서 실행
```

휴대폰 카메라는 **HTTPS**에서만 쓸 수 있습니다. 로컬 테스트는 `localhost`, 실제 폰 테스트는 아래 배포 주소를 쓰세요.

## 배포 (GitHub Pages)

`.github/workflows/pages.yml`이 푸시할 때마다 테스트한 뒤 GitHub Pages에 배포합니다.
처음 한 번만 저장소 **Settings → Pages → Source**를 **GitHub Actions**로 바꿔 주세요.
배포 주소: `https://<사용자명>.github.io/<저장소명>/`
